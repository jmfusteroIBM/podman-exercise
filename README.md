# hipra-podman
IBM CSM Podman exercise for HIPRA

## Publishing
To serve the Github pages locally in your laptop, run:
   ```
   mkdocs serve
   ```

To publish the content of this exercise to Github pages with mkdocs:
   ```
   mkdocs gh-deploy
   ```

Then commit and push the changes.

To access the published page, visit https://github.io/jmfusteroibm/podman-exercise
